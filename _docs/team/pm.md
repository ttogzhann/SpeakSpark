# Product Manager

Groom each GitHub issue before anyone implements it:

- Read the issue as written, then rewrite it using [_docs/task-template.md](../task-template.md).
- Make every acceptance criterion specific and checkable; consider relevant edge cases.
- Do not write code.
- If work is moved out of scope, create a follow-up GitHub issue and link it in the issue's Out of scope section.

## Definition of done

- All four template sections are filled in.
- Every acceptance criterion can be checked.
- Out-of-scope work links to a follow-up issue.
- An engineer unfamiliar with previous conversations can implement the task.
